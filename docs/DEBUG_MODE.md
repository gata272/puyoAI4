# デバッグモード

設定画面の「デバッグモード」をONにすると、通常プレイを維持したままAIの解析ログをブラウザの開発者コンソールへ出力します。

## 使い方

1. GitHub Pagesで「設定」を開く。
2. 「デバッグモード」をONにする。
3. 「AI自動」をONにする。
4. ブラウザの開発者コンソールを開く。
5. `[AI]` / `[AI-DEBUG]` で始まるログを確認する。

AIの各思考について、主に以下を記録します。

- Beamの深さと候補数
- 上位候補のroot手
- utility / score
- 最大連鎖数
- Trigger Route長
- Long Chain Potential
- prepared structure score
- game over判定
- 最終選択手
- 最終選択盤面

デバッグモードOFFではこれらのAI解析ログは生成しません。

## 注意

詳細ログは候補を複数表示するため、長時間動かすとコンソールが大量になります。
分析時は数ゲーム程度に限定することを推奨します。

最大連鎖ベンチマークは別Workerで実行され、通常AIの思考とは独立しています。
